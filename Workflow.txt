## State Management

```python
class ResearchState(TypedDict):
    topic: str                    # Original research topic
    research_notes: str          # Raw facts from Research Agent
    analysis: dict              # Structured analysis with advantages/disadvantages
    report: str                 # Draft report from Writer
    review: dict                # Reviewer feedback
    approved: bool              # Pass/fail quality check
    revision_count: int         # Track iteration loops
```

---

## Agent Flow Details

### Supervisor (Orchestrator)
```
Input:  topic
Tasks:
  1. Delegate to Research Agent
  2. Pass results to Analysis Agent
  3. Forward to Writer Agent
  4. Collect from Reviewer Agent
  5. Return final report
Output: Final report
```

### Research Agent (Fact Gathering)
```
Input:   topic
V1:      Use LLM context only
V2:      search(query) → web_urls(link) → extract_text(url)
Output:  research_notes: [fact1, fact2, fact3, ...]
```

### Analysis Agent (Comparison & Reasoning)
```
Input:   research_notes
Process: Compare findings, identify tradeoffs
Output:  {
           "advantages": [...],
           "disadvantages": [...],
           "key_points": [...]
         }
```

### Writer Agent (Report Generation)
```
Input:   research_notes + analysis
Format:  Markdown
Sections:
  - Introduction
  - Findings
  - Comparison Table
  - Tradeoffs
  - Conclusion
Output:  report (markdown)
```

### Reviewer Agent (Quality Gate)
```
Input:   report
Checks:
  ✓ Completeness
  ✓ Contradictions
  ✓ Clarity
  ✓ Evidence support
Output:  {
           "approved": bool,
           "feedback": [critique1, critique2, ...],
           "confidence": 0-1
         }
Approval: approved == true
Revision: approved == false → feedback to Writer
Loop:    Max 3 iterations
```

### Week 3: Add Approval Loop

**Loop Logic:**

## Key Patterns You'll Learn

| Pattern | Agent | How |
|---------|-------|-----|
| **Routing** | Supervisor | Route tasks to correct agent |
| **Tool Use** | Research | Call search/web tools |
| **Specialized Prompt** | Analysis | Domain-specific reasoning |
| **Structured Output** | Writer | Output specific format |
| **Self-Critique** | Reviewer | Loop back for improvement |
| **Conditional Flow** | Reviewer → Writer | If approved? route |
| **State Management** | All | Pass data through TypedDict |
| **Handoffs** | Supervisor | Pass between agents |

## Example Input/Output

### Input
```
Topic: Compare YOLO v8 vs DETR for object detection
```

### Research Agent Output (Week 1)
```
YOLO v8:
- Real-time detection
- 640x640 input
- Single-stage detector
- ~80 FPS on GPU

DETR:
- Transformer-based
- Slower inference
- End-to-end training
- Better for small objects
```

```json
{
```
